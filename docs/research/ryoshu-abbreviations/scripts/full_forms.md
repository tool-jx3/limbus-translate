# 良秀縮略語：補完整說法的判讀說明（第 3 輪）

第 3 輪把 `rows4.json`（`rows4.py` 產生）分成 7 份交給判讀者，每份依下列說明填寫；結果合併、套用抽查的更正與正規化（加點全詞改標「未縮」、「?」改全形「？」）後是 `full_forms.json`。

Limbus Company 的角色良秀（료슈）說話常把詞縮成字首加點（KR `모. 분.` = 모가지를 분질러…）。JP、EN、繁中（TW）譯文各自做了縮略。研究報告要一張表，每行列出 KR、JP、EN、TW 的縮略與**完整說法**，並標出完整說法的來源。

判讀者拿到一個 slice 檔（`rows4.json` 的一部分，JSON 陣列）。每個元素是一行：

- `id`：行號（回傳時照抄）
- `g`、`kr`、`kr_forms`：KR 縮略語
- `jp`／`jp_forms`、`en`／`en_forms`、`tw`：這一行對應的 JP、EN、TW 縮略片段（同一行裡這些寫法相同；EN 只差點、空格的算同一種）。`（不加點）`、`（未縮）`、`（無；譯「…」）`、`（用逗號）`、`（．的）` 是先前研究的標記，意思見下
- `locs`：這一行出現的所有位置（`檔案#dataList 位置`，RPG 是 `#項/句`）
- `expansion_known`：先前研究找到的劇中展開（KR），可能是空的
- `context`：前 3 個位置各自的上下文（前後各 3 個單位；`here: true` 是縮略語所在的單位）。每個單位有 `who`（說話者 model 或名字）、`loc`、`kr`、`jp`、`en`、`tw`
- `class`、`note`、`proposal`：先前的判定，供參考

標記的意思：`（不加點）` 該語言片段本身沒有點；`（未縮）`／`（無；譯「…」）` 該語言沒有縮，照字寫出；`（用逗號）` 用逗號代替點；`（．的）` 繁中末字後還有一個「．」接正文。

## 你要做的

每一行填 KR、JP、EN、TW 四種語言的**完整說法**與**來源**：

- **遊戲內**：遊戲文字裡**那個語言自己**明確說出完整說法——有人展開（「모가지를 분질러버리면」）、括號註明、更正、旁白解釋，或同一行就寫出了（EN 常見 `C.H. (Clock Head)`、`"knew it. W.A."`）。要附 `loc`（那個單位的位置，格式同 `context[].loc`，例 `StoryData/ES130B.json#10`）與 `who`（說話者；旁白寫「旁白」）。`full` 必須是那個單位該語言文字裡**原樣出現的一段**（可以只取對應的那幾個詞，不要改字、不要加字），腳本會逐字核對
  - JP／EN／TW 的「遊戲內」看的是該語言的譯文：KR 的展開句，其 JP／EN／TW 譯文若真的寫出了對應該語言縮略的詞，才算該語言的遊戲內；譯文沒有寫出（或寫出的詞對不上該語言縮略的字母／字），就不是遊戲內
- **推測**：沒有遊戲內的展開，從那個語言自己的那一行與上下文推出。完整說法要能**逐一對上**縮略的每一段（每個音節、每個假名或漢字、每個字母、每個中文字）。推得出就寫；只有部分確定時，不確定的部分加「？」；完全推不出寫 `不明`（full 留空）
  - KR 的推測以 KR 上下文為主；JP、EN、TW 只能佐證，不能單獨決定 KR 的讀法（若只靠它們，`remark` 註明「KR 無根據，依 JP／EN」）
  - 該語言**沒有縮**（`（未縮）`、`（無；譯「…」）`、`（不加點）` 而且本來就是完整詞）時，full 寫那個詞本身，source 寫 `未縮`
- 每種語言各自判斷；不要把 KR 的意思硬套到 JP／EN／TW。EN 常另造縮寫（`S.Y.N.C.`、`S.A.N.G.R.I.A.`），JP 常換詞，照它們自己的字推
- 可以用 `python3 -I scene.py <檔案路徑> <起> <迄> kjez`（在本目錄執行）看更長的場景，例：`python3 -I scene.py StoryData/S940B.json 10 40 kjez`。RPG 檔用不了 scene.py，就只看 context
- **不要捏造**：寫不出來寧可 `不明`。不要上網查。

## 回傳格式

把結果寫成 JSON 陣列到輸出檔，每行一個物件（照輸入順序、每個 id 都要有）：

```json
{"id": 12,
 "kr": {"full": "모가지를 분질러버리면", "source": "遊戲內", "loc": "StoryData/ES130B.json#10", "who": "싱클레어"},
 "jp": {"full": "首をへし折れば", "source": "推測"},
 "en": {"full": "Snap Your Neck, Cunt?", "source": "推測"},
 "tw": {"full": "脖子扭斷", "source": "推測"},
 "remark": ""}
```

- `source` 只能是 `遊戲內`、`推測`、`未縮`、`不明`
- `遊戲內` 必須有 `loc`、`who`；其他不要 `loc`
- `remark`：一行內的簡短附註（例如「KR 無根據，依 JP／EN」「劇中誤讀」「雙關」），沒有就空字串
- 完整說法用該語言寫（KR 寫韓文、JP 寫日文、EN 寫英文、TW 寫繁體中文）

寫完後確認是合法 JSON、筆數與輸入相同；合併後以 `check_full.py` 核對。
