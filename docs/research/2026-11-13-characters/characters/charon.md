# 卡戎（charon）

> 資料：`charon.lines.tsv` 163 行（model 全為 `카론`，60 個檔案）。其中 E001X#279、#280、#303、#304、#335–#341 共 11 行是「交換身體」事件裡**維吉里烏斯在卡戎身體裡說話**（見 2.5），下文的「本人」統計扣掉這 11 行，以 **152 行**為母數。數字都由腳本實算。

## 1. 角色概要

- 邊獄公司巴士「梅菲斯托費勒斯」（她叫「메피」→梅菲）的司機，女性；維吉里烏斯是她的照顧者。wiki 形容她「offbeat, childishly strange Bus Driver」，「卡戎」這個人格困在 Lapis 的身體裡、沒有 Lapis 的記憶（https://limbuscompany.wiki.gg/wiki/Charon ；本環境連不上該站，內容取自搜尋結果摘要）。
- 劇情裡多半在開車、停車、出發時插一兩句話，或對罪人的行為下簡短評語；幾乎只對維吉里烏斯撒嬌、抱怨。
- 活動劇情另有兩種特殊情境：E001X「交換身體」（她許願讓大家互換，維吉里烏斯進了她的身體）、E003*「幼稚園」AU（她是「카론 선생님」，但丁是「원장님」）。

## 2. KR 說話方式

### 2.1 語體

- **반말，句子極短**。本人 152 行，最後一句是반말或無述語片段的有 147 行（97%）。另外常夾**無述語的名詞句、狀聲詞句**：152 行中 70 行至少有一句沒有述語。
  - `S1003B#18`：조용한 버스. 카론은 재미없어. → 安靜的巴士。卡戎覺得無聊。
  - `S105B#52`：메피 배, 빵빵. 카론도 빵빵. → 梅菲的肚子，砰砰。卡戎也砰砰。
  - `E003I2#110`：걱정. 필요 없어, 원장님. → 擔心。不需要，園長。
- **用逗號把句子切開**，特別是在否定、述語前（`무르기, 없기야`、`졸음 운전, 안 해`、`유턴, 없어`）。
  - `E001X#34`：무르기, 없기야. → 不能、反悔哦。
  - `E020X#5`：카론, 졸려. 훌륭한 버스 기사는 졸음 운전, 안 해. → 卡戎，很睏。優秀的巴士司機，不會疲勞駕駛。
  - `S606B#58`：메피에는 유턴, 없어. → 梅菲，不會掉頭。
- **報告式的 -다 平敘句**混在반말裡（4 行），像機器播報：
  - `S109B#1`：도착했다. 역시 카론은 길을 알았던 거야. → 我們到了。果然卡戎一直都認得路。
  - `S003A#14`：메피는 항상 배고프다. 그래서 울어. → 梅菲永遠餓著肚子。所以會哭泣。
- **少數非반말句尾**（5 行）：
  - 합쇼체 2 行，鬧彆扭或像在報告：`S309B#5`：베르, 카론은 지금을 기억할 것입니다. → 維吉，卡戎記下這一次了。／`S004A#19`：매우. 신나. 날아갈 것 같습니다, 카론. → 非常。興奮。像飛在天上，卡戎。（JP 都用です／ます；EN 後者作「reports Charon」）
  - `S101B#23`：다시 한번 말하자면, 내 이름은 카론이요. → 再說一遍，我的名字叫卡戎。（格里高爾叫她「기사 양반」時，刻意糾正；JP 用だ，看不出明確語體轉換）
  - 引用或讀紙條：`S101B#29`：'수감자들은 4구로 간다.' → 「罪人們將前往4區。」（轉述維吉里烏斯）、`S106B#9`：마음이 향하는 곳. 그곳에 진짜 길이 있을지니. → 遵從心之所向。那便是真正的道路所在。
- 對誰都一樣：對維吉里烏斯、罪人、敵人、AU 的「園長」都用반말；激動時沒有改變語體，只是更短（`E042X#13`：비상. 비상. 메피가 터질 것처럼 울고 있어. 메피 아파? → 嘀嗚。嘀嗚。梅菲哭得撕心裂肺。梅菲，生病了嗎？）。

### 2.2 自稱

- **主要用自己的名字「카론」**：本人 152 行中 51 行有「카론」指自己；用 나／난／내 的只有 4 行（S002B#4、S101B#23、S106B#15、S708B#89）。
  - `S502B#16`：카론, 심심해. 카론은 운전 하고 싶은데. → 卡戎，好無聊。卡戎想要駕駛。
  - `E617B#41`：카론은 돌아가고 싶어. 메피, 외로울 거야. → 卡戎想回去。梅菲，會覺得寂寞。
  - `S106B#15`：분홍 머리가 계속 재잘거려. 난 길을 알고 있단 말이야. → 粉色頭髮一直囉哩囉嗦。我明明知道該怎麼走。（少數用 난 的例子）
- **「카론, ＋述語」**：名字後不接助詞、直接逗號，像報告自己的狀態（14 行）。
  - `S503B#6`：카론, 놀랐어. 주황 머리… 신선해. → 卡戎，嚇一跳。橘頭髮的……新鮮。
  - `S515B#6`：노랑머리, 생선 핥아? 그런 취향? 카론, 덜덜. → 黃髮，會舔魚嗎？奇怪的興趣？卡戎，嚇到。
  - `S309B#2`：늦었어. 카론, 백까지 셌는데도 너희 안 왔어. → 真慢。卡戎，數到一百了你們都沒來。
- 身分自稱「버스 기사」（巴士司機）：`S002B#4`：상쾌한 아침. 나는야 버스 기사. 카론. → 清爽的早晨。我是巴士司機。卡戎。；`S002B#176`：버스 기사는 졸음 쉼터에서만 졸아, 베르. → 巴士司機只會在休息點打嗑睡，維吉。
- 幼稚園 AU 自稱「카론 선생님」：`E003I3#52`：카론 선생님, 저런 말 안 가르쳐. 책임, 아냐. → 卡戎老師，沒教過那種話。責任，不是我的。

### 2.5 變體與特殊情境

StoryData 裡卡戎只有 `카론` 一個 model（指引列的 `카론만우` 在 StoryData 沒有台詞）。語氣差異來自情境：

- **E001X 交換身體**：E001X#248 以後，`카론` model 的 #279–#341（11 行）是**維吉里烏斯**在卡戎身體裡說話（합쇼체對但丁、하다체、나／네 녀석들、自稱「붉은시선」），`베르길리우스` model 的 #248–#351 才是卡戎（`사탕… 언제 줘?`、`전원. 하. 차.`）。
  - `E001X#280`：대체 어떤 기가 막힌 소원을 별에 대고 빌었길래 이딴 난장판이 벌어지는 겁니까… → 你究竟向星星許下了何等荒謬的願望，才搞出了這種爛攤子……
  - `E001X#336`：카론은 글라디우스의 사용법을 모른다. 전투 경험도 없다고 봐도 무방하지. → 卡戎不知道那把羅馬短劍的用法，說是沒有任何戰鬥經驗也不為過吧。
  - `E001X#341`：그 대가를 톡톡히… 치르게 해주겠다. → 我會讓你們為此……付出代價。
  - 交換前的卡戎本人：`E001X#33`：소원, 빌 때는… → 許願、的時候……；事後 `E002X#36`：소원은, 신중히. 무르기 없다고. → 認真，許願。不能反悔。
  - 現行 TW 這幾行已照維吉里烏斯的口吻、對但丁用「你」（符合 `vergilius.md`「對但丁的第二人稱一律用你」）。
- **E003* 幼稚園 AU**：說話方式不變，只是自稱「카론 선생님」、叫但丁「원장님」（E003I3#52、E003I2#110）；同事尤莉叫她「카론 선생님」。
  - `E003X#28`：하나는 밖에 싸돌아 다녀. 카론은 걱정 안해. → 有一個在外面到處亂跑。卡戎不擔心。
