## Global Constraints

- Module path：`github.com/tool-jx3/limbus-translate`；`go.mod` 宣告 `go 1.26.1`
- 程式碼授權 GPL-3.0（`LICENSE`）；`guides/`、`glossary/`、`rules/` 與 `tw` 分支譯文為 CC BY-NC-SA 4.0（`LICENSE-CONTENT`）

- `kr_sha`：KR 字串把 `\r\n` 換成 `\n` 後的 sha256（小寫 hex）
- `origin` 只能是 `paratranz`、`claude`、`human`、`copy`、`fallback`
- 輸出 JSON：UTF-8 無 BOM、LF、2 空格縮排、不跳脫 `<`、`>`、`&`、保留 KR 的鍵順序與數字原文、檔尾換行；同樣輸入必須產生相同位元組

- 檔案集合以 KR 為準；只有 EN 有的檔不輸出
- 凍結清單：`BgmLyrics/**`
- 每個 CLI 指令支援 `--json`；exit code 0 成功、1 有發現或使用者錯誤、2 系統錯誤
- Paratranz 有效譯文：≠ EN（EN ≠ KR 時）、≠ KR、不含諺文、含漢字
- 同一單位驗證失敗 3 次 → `needs_review`，暫用 EN 原文（無 EN 用 KR），`origin=fallback`

1. 字串含 `\n`、`"`、`\\`、emoji、`<color=#ff0000>` 時，parse → marshal 必須語意不變，且 `<`、`>` 不被跳脫 — Task 2 `TestRoundTripEscapes`

### Task 4: 跨語言對齊（`internal/align`）

**Files:**
- Create: `internal/align/lang.go`、`internal/align/lcs.go`、`internal/align/lang_test.go`、`testdata/align/*.json`

**Interfaces:**
- Consumes: `jsonx`、`units.Extract`
- Produces:
  - `type Method string`：`MethodPointer="pointer"`、`MethodID="id"`、`MethodSequence="sequence"`
  - `type LangAligned struct{ Value string; Method Method }`
  - `func AlignLang(file string, kr, other *jsonx.Node) map[string]LangAligned`（key 為 KR pointer；未對齊的不放入 map）
  - `func LCS[T comparable](a, b []T) [][2]int`（回傳配對索引，遞增）

演算法（spec §6.5）：
1. 兩邊都有 `dataList` 陣列時才做條目層對齊；否則同 pointer 直接對應（`pointer`）
2. 兩邊條目序列完全相同（以「指紋」比）→ 同 pointer（`pointer`）
3. 非 `StoryData/` 開頭、兩邊每條都有 `id` 且各自唯一、KR 條目 ≥ 90% 找得到同 id → 依 id 配對（`id`）
4. 其餘 → 指紋序列做 LCS（`sequence`）。指紋 = (`model` 值, 除 `id` 外的鍵名排序後串接)
5. 配對條目內：字串依相對 pointer 對應；巢狀陣列元素若有 `id` 依 id，否則依位置
6. 配對後兩邊的 `model` 不同 → 該條目所有單位不放入結果
