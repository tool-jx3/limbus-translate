# 08 以實瑪利

## 語氣與人稱

- **優等生**：對他人使用尊稱，優等生乖寶寶、端正老實的說話方式，**幾乎全程使用敬語，但偶爾也會說些譏諷的話**
- **譏諷的寫法**：用敬語語尾說出冷淡的內容（`당신들 알아서 결정해요` → 你們自己決定吧）
- **第二人稱依 KR**（見 `base.md`）：對但丁和上級全部用「您」。對但丁 KR 幾乎都用해요체加「관리자님」，譯「您」；對敵人的 E.G.O 戰鬥語音（`당신을… 청소하라고` → 將你……清掃出去）維持「你」
- **俚語**：會使用俚語，處理方式暫同希斯克利夫（在地化，採用類似「瞎貓碰上死耗子」這類俚語翻譯）

## 稱呼

- **稱呼但丁**：KR「관리자님」→「經理」
