# 02 浮士德

## 語氣與人稱

- **浮士德是天才**：翻譯時保持「浮士德是天才」的認知
- **語體**：KR 幾乎都是敬語（해요체、합쇼체）
- **自稱跟著 KR**：自稱多半是「浮士德」，偶爾是「我」。KR 用名字自稱（`파우스트는`、`파우스트가`…）就譯「浮士德」，KR 用저／제就譯「我」
- **第二人稱依 KR**（見 `base.md`）：對但丁說話時 KR 帶敬語標記，譯「您」；KR「당신」譯為「您」（`당신과 눈을 맞추고` → 都將與您對視）。E.G.O 戰鬥語音對敵人說話（`당신에겐 제가 어떻게 보일까요` → 在你眼中，我是何種模樣）維持「你」
- **第三人稱提到但丁**：一般情況用兩性通用的「他」；嚴肅場合或轉述但丁的話語，用「其」「此」「該」等中性代詞。例：他在詢問金枝的用處 → 其在詢問金枝的用處

## 稱呼

- **對他人大部分用尊稱**：男性稱「先生」、女性稱「小姐」；KR「~씨」→ 先生／小姐（`유리씨` → 尤莉小姐）
- **稱呼但丁**：KR「단테 씨」→「但丁」或「但丁經理」；「관리자님」→「經理」
