# 04 良秀

## 原指引

- 對他人很少直呼名諱，沒有使用過尊稱。
- 多使用縮略語、說話比較帥（？），**良秀是自由的。**

## 資料補充

> 依據：既有繁中良秀台詞 1,454 行（劇情 1,069 行＋語音 385 行）；縮略語：raw-20261105 良秀 KR 台詞 2,596 行（含過去的本人）中 353 行、386 處、約 285 種，多數只出現一次

- **KR 語體**：반말 96%，幾乎不用敬語
- **稱呼但丁**：KR「관리자」→「但丁」或「經理」，不加敬稱
- 句子短、語尾助詞少（「啊」「吧」各約 6%），刪節號比例也低

### 縮略語：KR 怎麼縮

- **每個詞（語節）取第一個音節**，助詞、語尾不取：`모.분.`＝모가지를 분질러（S101B#46）、`남.손.다.분`＝남은 손가락을 다 분질러（2D102B#18）
- **每個音節後加「.」**（376／386 處）；有無空格（`모. 분.` 252、`모.분.` 124）意思相同；末字通常也加點（343／376），接助詞、하다、이다或問號時可省（`버.안에서`、`시. 대?`）
- 也截取人名、長詞的音節（`히.클.` 히스클리프、`어.떠.` 어중이떠중이），或把短詞逐字加點（`젠.장.`）；常縮別人剛說的話（`림.컴.수.` ← S701B#64），也常整句只有縮略語（110／353 行）

### 縮略語：譯法

- **先把完整意思譯成中文，再從每個詞取一個代表字（多半是首字），照中文語序**，全形「．」隔開，末字後不加（既有 350／353 行，無其他分隔符；字數＝KR 音節數 332／382）：`모.분.`（扭斷脖子）→ 脖．扭；`요. 넘. 맛.` → 菜．超．讚（E912B#31）
- 要能還原：人名取中文譯名首字，不照 KR 的音（`그.로.싱.이.` → 格．羅．辛．李）；KR 沒加點的不加點（S101B#45、S111B#28）
- JP「く・へ」、EN「S.Y.N.C.」都另造說法，只用來確認是縮略語，意思依 KR

### 縮略語：劇中展開或猜測時

- 同場景有人展開（辛克萊 29 次、良秀自己 26 次、莫梭 7 次）：每個字都要在展開句的譯文裡找得到，兩句一起譯：`타. 무. 아니… 타겟 무력화.` → 目．無。不……目標無效化。（Voice_Ryoshu_LCCB_10406#17）
- 有人猜錯或一語雙關時，兩種讀法都要能從同一組字讀出：`시. 비.`（莫梭「時鐘，挪開」／良秀「時間被挪移了嗎」，RPG floor-b2#105）→ 時．挪；`임. 동.`（臨時同盟／臨時同行，E908B#110）→ 臨．同
- 展開不同就可以不同：`모.불.아.위.`（…아름다움／아라야를 위해）→ 縱．焚．僅．美／阿（Voice_EGO_Ryoshu_4#0、#1）

## 與阿賴耶的縮略語不同

- 阿賴耶（良秀之女，見 `characters/araya.md`）說的是學校學來的流行語，**不加點、寫成一個詞**（세젤맛、별다줄、감다뒤、완소、수먹아，KR 0／10 加點）；良秀加點（376／386）。她還糾正良秀「그렇게 줄이는 거 아니라고」（S919B#1、S947B#217、S949A#127）。同場景兩人都縮寫時，良秀用「．」，阿賴耶用不加點的中文說法（既有：品死、世一好吃、全縮、媽最愛）
- 良秀借用她的詞時不加點：`감다뒤`（Voice_Ryoshu_KumoPinky_10415#20 品死）、`완소`（Announcer_Ryoshu_42#11）；S951B#24 良秀試說 `안심안지… 유잼`，辛克萊說她「簡稱變自然了」，她又改回 `재. 없.`（#28）
- 第九章結尾：阿賴耶「…완소야」→ 良秀 `너. 내. 소. 딸.`（너는 내 소중한 딸，S949A#121–124），中文要接得上阿賴耶的「最愛」（待確認）
