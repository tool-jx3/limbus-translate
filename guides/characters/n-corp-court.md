# N公司法院

## 身分

- **N公司法院**：第 10 章在 N 公司法院審判莫梭、判處薛西弗斯刑的法官、檢察官與法警（S1004B）
- **過去的審判**：S1042B、S1060B 是莫梭回憶的過去審判（地點 `과거, N사 법정`），反覆追問 `왜 어머니를 죽였는가`；S1037B 也有同一句的幻聽

## 語氣與人稱

- **法官**：幾乎都是法庭的해라체（`~는가`、`~하라`、`~바이다`），只對辯護人用합쇼체
- **檢察官**：對審判長用합쇼체
- **法警**：用합쇼체
- **法庭用語**：中文用正式的法庭用語（既有「被告」「檢方／辯方」「准許發言」「主文」）

## 稱呼

- **檢察官稱法官**：`재판장님` → 審判長
- **法官稱人**：`피고(인)` → 被告（人），`변호인` → 辯護人，`검사 측` → 檢方

## 用語

- **說話者名稱**：`판사` → 法官，`검사` → 檢察官，`법정 경위` → 法警
