# 異端審判官

## 身分

- **N公司的異端審判官**：侍奉執柄者（`쥐는 자`）；在路上攔下巴士，要罪人砍下「不潔的旅者」的頭獻上，拷問義體使用者（S322B）
- **3D301B**：兩人輪流重複同一句

## 語氣與人稱

- **文言腔**：幾乎都是古風的해라체與文言語尾（`~도다`、`~지니`、`~리라`、`~거라`）；照 `base.md` 的極古風語尾，中文用文言腔
- **自稱**：`우리` → 我等
- **同一檔用同一種稱呼**：既有對人「汝等」「爾等」混用，同一檔宜一致

## 稱呼

- **對人**：`그대`、`그대들` → 汝、汝等

## 用語

- **쥐는 자**：→ 執柄者（詞彙表）
- **이단**：→ 異端
- **說話者名稱**：`이단심문관 1` → 異端審判官1、`이단심문관 2` → 異端審判官2；`고문하는`／`심문에 능한 N사～` → 進行拷問的／擅長審訊的N公司異端審判官
