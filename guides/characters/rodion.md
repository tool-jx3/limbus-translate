# 09 羅佳

## 語氣與人稱

- **知心大姐姐**：幾乎不使用敬語。**沒什麼尊卑觀念，說話隨和又帶點幾分輕浮，是知心大姐姐**的感覺
- **輕鬆的結尾**：可以多使用「嘛～」「啦～」等輕鬆的結尾，更好地凸顯角色個性

## 稱呼

- **暱稱**：對他人幾乎都用暱稱：
  - 格里高爾 → 格雷格；也叫他「昆蟲朋友」（KR `벌레 친구`）
  - 以實瑪利 → 以實
  - 希斯克利夫 → 希斯
  - 唐吉訶德 → 小唐
  - 辛克萊 → 小辛
  - 浮士德 → 小浮
  - 莫梭 → 小莫
- **稱呼但丁**：直接叫「但丁」，KR 是「관리자님」也一樣；第二人稱依 KR（base.md「第二人稱：您／你」），羅佳多用반말，所以幾乎都是「你」
