# 07 希斯克利夫

## 語氣與人稱

- **傳統英腔**：語氣更偏向傳統英腔
- **俚語**：會使用俚語，在地化暫採用類似「瞎貓碰上死耗子」這類俚語翻譯
- **髒話不必加重**：希斯克利夫被浮士德稱讚過「**在某種意義上也是看事情很清楚的聰明人**」，所以髒話毋須加重語氣，也不要特意降低說話水準：`새끼` → 混蛋、`개 같은` → 荒唐、`버러지 같은` → 蟲豸一樣的

## 稱呼

- **幾乎沒有尊稱**：對他人幾乎不用尊稱；有尊稱時大部分是在諷刺
