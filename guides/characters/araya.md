# 阿賴耶

## 身分

- **良秀的女兒**：叫良秀「엄마」（媽媽）
- **長大後**：`아라야10대`、`아라야20대`、`아라야정장*` 語氣較成熟，看劇情判斷
- **`소지아비*`**：小指父輩（地慧星）的 key。`소지아비3`、`소지아비얼굴` 是第 9 章假扮前任地慧星的阿賴耶：語氣照劇情裡地慧星的口吻，不用她的流行語。其他 `소지아비*` 不在本指引：成年的阿賴耶以 teller 아라야 用它說話，同一組 key 也是前任（回憶），看劇情判斷

## 語氣與人稱

- **小學生口語**：常拉長或撒嬌地拼字（갠찮어、그리구、이쁘자나、무서어）；中文用孩子的口吻（既有「不是那樣啦」「好好學哦」）

## 稱呼

- **叫良秀**：拉長成 `료-슈` 時，照 `shared/ruby.md` 寫 `<ruby=りょーしゅー>良秀</ruby>`

## 縮略語：學校學來的流行語

- **不加點、寫成一個詞**：放在句子裡用（세젤맛、별다줄、감다뒤、완소、수먹아，KR 都不加點）；良秀的縮略語幾乎都加點，見 `characters/ryoshu.md`「與阿賴耶的縮略語不同」。JP、EN 也分開寫：她是 センシ、GOAT、SMH，良秀是 く・へ、S.Y.N.C.
- **中文也寫成不加「．」的流行語**：從同場景的完整說法取字，讓解釋接得上：`감이… 다… 뒤졌다아… 자! 그래서 감다뒤!` → 品味……死光光了……你看！所以是品死！

| KR | 劇中的完整說法 | 既有繁中 |
|---|---|---|
| 세젤맛 | 세상에서 제일 맛있다 | 世一好吃 |
| 별다줄 | 별걸 다 줄이는군（良秀） | 全縮 |
| 감다뒤 | 감이 다 뒤졌다 | 品死 |
| 완소 | （未展開；推定 완전 소중） | 最愛（「對我來說，媽最愛！」的「媽」是 엄마는） |
| 수먹아 | 수박 먹어, 아라야（良秀） | 吃西耶 |
| 오키、암툰、당근 | （未展開；推定 OK、아무튼、당연하지） | OK、總之、當然 |

- **同一個詞在不同檔案要一樣**：良秀借用時也照這裡的寫法（`감다뒤` → 品死；`완소` → 「…最愛…」）
- **逐字強調時才加點**：逐字強調一個詞才加點，這不是縮略語：`란.도.셀!`、`초.등.학.생!` → 雙．肩．背．包！、小．學．生！
- **不縮人名**：她不縮人名，還會糾正良秀加點的縮法：`그렇게 줄이는 거 아니라고`、`또 이상하게 줄였지?`
