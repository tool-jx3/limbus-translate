# 豆豆幫

## 身分

- **後巷的幫派**：第 2 章後巷的幫派（EN Tingtang Gang），向當鋪老闆收保護費；老大在汽車塔

## 語氣與人稱

- **語體**：幾乎都是반말；합쇼체只在成員對老大說話時。帶方言（`~랑게`、`~거여`、`느이`、`작것들`），中文用粗俗的流氓口吻
- **自稱**：`우리` → 我們（「우리 가족」「우리 막내」）

## 稱呼

- **當鋪老闆**：`할배`、`영감` → 老頭
- **罪人**：`작것들`、`새끼들`、`아가들` → 雜碎、臭小鬼、菜鳥們
- **老大**：`형님` → 大哥

## 用語

- **說話者名稱**：`콩콩이파` → 豆豆幫，各 teller 一致；`촌스러운 말투의～` → 俗氣的豆豆幫成員。model `촌스러운말투의콩콩파조직원` 在 S203B 也有 teller 是 `세보이고 싶었던～` 的行（想表現得很強壯的豆豆幫成員）
