# 小矮人

## 身分

- **禮物工廠的小矮人**：郊區禮物工廠的小矮人（노움），在多多魯科長（도도루 실장）手下把人類當「禮物材料」處理

## 語氣與人稱

- **語體**：全用반말
- **口癖「~움／~숨」**：句尾黏上口癖「~움／~숨」（갖고 왔숨、맞움、것이움），中文在句尾加「諾姆」。同為小矮人的多多魯（`도도루`，有名字，不在本群組）也有同一口癖

## 稱呼

- **多多魯**：`도도루 실장` → 多多魯科長

## 用語

- **說話者名稱**：`빨간노움` → 紅色小矮人、`초록노움` → 綠色小矮人、`검은노움` → 黑色小矮人
- **「小矮人」與「諾姆」並存**：名稱用「小矮人」、口癖用音譯「諾姆」
