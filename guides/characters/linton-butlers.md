# 林頓家的管家

## 身分

- **林頓家的管家**：侍奉林頓（埃德加家）的管家，奉命在凱瑟琳房裡找日記、提醒奈莉死兔幫來路不明

## 語氣與人稱

- **語體**：對奈莉、辛德利、林頓用합쇼체；對希斯克利夫轉為반말（`말이 지나치군.`）。中文對上用「請」「您」，對希斯克利夫改用「你」、語氣冷硬
- **自稱**：`저희` → 我們

## 稱呼

- **奈莉、辛德利**：`넬리님` → 奈莉大人；`힌들리 씨` → 辛德利先生
- **林頓**：`린튼 주인님` → 林頓家主

## 用語

- **說話者名稱**：`조심스러운 버틀러` → 謹慎的管家、`엄격한 버틀러` → 嚴格的管家；버틀러 依詞彙表寫「管家」

## 待確認

- **譯文補出的林頓**：KR 沒有寫出林頓、譯文另補主語時，既有譯文有寫「林頓大人」的；提案統一寫「林頓家主」
- **對凱瑟琳的稱呼**：既有 `캐서린 주인님` → 凱瑟琳小姐、`캐서린 님` → 凱瑟琳大人；要與奈莉等角色一併決定
