# 共通翻譯原則

## 來源語言

- 以 KR 韓文為主，JP 日文與 EN 英文作為輔助。KR 與 EN 意思不同時，依 KR
- 遇到本指引未說明的情況，優先參考韓文原文

## 與程式語言有關的翻譯須知

### 原指引

***多為技能組使用。***

1. 在 `[]` 或 `<>` 裡面的英文不要翻譯或改動。
2. 在格式 `<XXX="這是">文字內容</XXX>` 中，`<XXX>` 是開始，`</XXX>` 是結束，不可以讓它變成 `</XXX>文字內容<XXX="這是">`
3. 可能會發現 `&lt;` 和 `&gt;` 的存在，`&lt;` 是 `<`，而 `&gt;` 是 `>`。
   - 這種狀況是因為 ParaTranz 會自動轉譯（限英／日），所以如果出現這個問題，請自行腦補。
4. 在翻譯時，`[]` 內會放置效果的英文。
   - 例如 **[Laceration]**，在遊戲裡面會顯示為**流血**。
5. `[xxx]` 都可以用中文字＋空格替代。
   - 例如 `[Combustion]` = 燒傷＋空格。
   - 然而，請盡量用 `[]` 而非中文＋空格。
6. 關於 `[]`、`<>` 符號。
   - 針對 `[]`，在其前後須各空一格半形。（※ `[]` 位於開頭則前方不需空格，遇到全形符號不需空格）
   - 針對 `<>`，前後則無須空格。
   - 當 `[]` 與 `[]` 相鄰時，彼此之間空一格半形。
   - `[TabExplain]` 用來阻擋關鍵字觸發，無任何效果。不可以在 `[` 前空格，但在 `]` 後若需空格可空格。
7. 任何括號都使用半形。
8. `，`／`。`／`：` 使用全形符號。
9. 針對具有強度與層數的狀態，請依範例格式書寫：「1**級**流血**強度**」、「1**回**流血 」、「1**層**易損」。
   - 請勿寫成「1**級**流血**   **」、「1**回**流血**回數**」、「1**層**易損**層數**」。
10. 如果遇到本篇須知未說明的格式問題，請優先參考韓文翻譯或提出詢問。

### 資料補充

> 依據：既有繁中 163,252 行，其中技能類（`Skills*`、`Passive*`、`Bufs*`、`BattleKeywords*`、`EGOgift*`、`Enemies*`、`PanicInfo*`）46,159 行

- **第 1、4、5 條**：KR 裡的 `[英文ID]` 有 97.6%（44,158／45,246）原樣保留；1,088 處改成「中文＋空格」
- **第 6 條**：`[ID]` 前空格正確 53,364 處、後空格正確 53,657 處。例外集中在兩類：
  - 複合名稱：`釘[Console]`、`釘[Breakpoint]`，`[` 前不空格（543 處多屬此類）
  - 全大寫的替換變數：`擁有[ATTRIBUTES]屬性攻擊技能的`，前後都不空格（250 處多屬此類）
- **第 7 條**：中文旁的半形括號 6,593 行，全形括號 815 行，以半形為主
- **第 8 條**：半形逗號只出現 3 處，已是全形
- **第 9 條**在 `[]` 寫法下的實際格式：
  - 強度：`2級 [Vibration] 強度`（5,037 行）
  - 回數：`3回 [Combustion]`（4,360 行）
  - 層數：`2層 [Protection]`（4,528 行）
  - 中文寫法：`3級呼吸法 強度`（1,885 行；依補充規則改回 `[ID]`）
  - 「強度與回數之和」這類把「強度」「回數」「層數」當名詞用的句子不在禁止之列
- **第 5 條的中文寫法**：改成「中文＋空格」的 1,088 處，幾乎都在 `Skills*`（842）、`Passives*`（157）、`EGOgift*`（56）。最常見的是 `[Laceration]` 流血（362）、`[Burst]` 破裂（82）、`[DefenseDown]` 防禦等級降低（63）、`[Sinking]` 沉淪（55）、`[Combustion]` 燒傷（50）。中文名稱與 `BattleKeywords*`／`Bufs*` 的官方名稱一致的有 1,079 處，不一致的 4 處（例如 `[DefenseDown]` 寫成「防禦等級減少」，官方是「防禦等級降低」）
- **第 3 條**：直接讀官方 JSON 不會產生 `&lt;`、`&gt;`；若譯文出現，驗證會把它還原成 `<`、`>`

### 補充規則（已決定）

- **一律保留 `[英文ID]`，不用中文＋空格替代**（取代原指引第 5 條「都可以用中文字＋空格替代」）。KR 原文寫 `[ID]` 的地方，譯文也必須寫同一個 `[ID]`
- 第 9 條的格式因此固定為：`1級 [Laceration] 強度`、`1回 [Laceration]`、`1層 [Vulnerable]`
- **KR 寫韓文狀態名、沒有 `[ID]` 時**：寫官方中文名，前後不加空格（`1級燒傷強度`、`2層守護`）。官方中文名以語言包的 `Bufs*`／`BattleKeywords*` 為準
- 既有譯文中改成中文的 1,088 處，第一階段匯入時還原為 `[ID]`：中文名稱與官方名稱一致的 1,079 處可以機械還原，其餘交給 Claude 依 KR 修正
- **全大寫的替換變數**（如 `[ATTRIBUTES]`）是程式在執行時代入的值，前後**不加空格**：`擁有[ATTRIBUTES]屬性攻擊技能的`
- **標籤**：有 205 行 KR 帶某種標籤（如 `<style>`）而譯文少了，多在 `EGOgift_MirrorDungeon*`。驗證要逐一比對標籤種類與數量
- **語言樣式標籤**：歌詞等處的 `<style="dkr…">` 是韓文版的語言樣式（EN 為 `den…`、JP 為 `djp…`）。譯文一律寫 `djp…`、保留後綴（如 `djp_CP6_2`、`DJP_CP9_1`），與三個中文社群包相同；驗證把三者視為相同的標籤，正規化會自動改成 `djp`。
- **多出的結束標籤**：KR 開了沒關的標籤（例如歌詞的 `<style="dkr">`），譯文可以在句尾補上對應的結束標籤，官方 EN 版也這樣寫；其他標籤數量仍須與 KR 相同。
- **ruby 注音**：KR 的 `<ruby=注音>本文</ruby>` 中，注音是顯示在本文上方的文字，要和本文一起翻譯（例如 `<ruby=천퇴성>삽시호</ruby>` → `<ruby=天退星>插翅虎</ruby>`）；標籤本身保留
- **但丁台詞開頭是英文詞時**：`<` 後的英文詞與後面的字之間不要加空格（寫「<N公司……>」，不寫「<N 公司……>」），否則會被當成標籤

## 標點與書寫

### 資料補充

| 項目 | 既有繁中用法 | 次數 |
|---|---|---|
| 刪節號 | `……` | 28,769 行（`...` 只有 12 行） |
| 引號 | `「」`、`『』` | 3,571 行（`“”` 只有 4 行） |
| 波浪號 | `～`（全形） | 1,433 行（`~` 55 行） |
| 破折號 | `——` | 242 行 |
| 驚嘆號、問號 | 全形 `！`、`？` | |

- 全形 `～` 在現行字型（Sarasa Gothic TC）能正常顯示，所以沿用。其他專案說「遊戲字型缺 `～`」是指他們的簡中字型；換字型時要重新檢查字元涵蓋
- 但丁的台詞整句包在 `<…>` 裡（2,184／2,189 行），譯文完整保留，見 `characters/dante.md`

### 補充規則（已決定）

- **只有數字或符號的 KR**：照抄，只把標點換成上表的寫法（例如 `...` → `……`、`?!` → `？！`）
- **換行**：KR 有換行時，譯文在對應的位置換行
- **只有刪節號的行**：KR 只有 `…`、`……` 或 `…….` 時一律寫 `……`；刪節號後面不加 `。`（既有繁中 1,699 行皆如此；JP 的 `……。` 是日文習慣）
- **亂碼與遮蔽字串**：KR 以符號表示的亂碼或遮蔽字（例如 `#&*()!#%의 #*%`）符號照原樣保留、不轉成全形，只翻譯其中的韓文（`의` → `的`）
- **清單符號**：KR 的 `·` 寫成 `．`（既有繁中 94 處皆如此）
- **字面的 `\n`**：KR 文字中出現反斜線加 n（`\n` 兩個字元，不是真正的換行）時，譯文在對應位置照樣保留
- **樓層**：名稱、地點、介面標籤寫 `3F`、`B2F`（例如「3F 樓層經理」）；對話與敘述寫「3樓」「地下2樓」（既有 RPG 與語音的寫法）
- **以 `<ruby>` 表現的雙關**：KR 沒有 `<ruby>` 標籤時，譯文也不加。修正 Paratranz 草稿時，草稿的 `<ruby=X>Y</ruby>` 一律改寫成「Y(X)」（半形括號，例如「研心(研尋)」「夜良秀苦(請多指教)」），不可直接刪掉；只有 X 單純是外語原文或讀音、沒有雙關時（例如 `<ruby=Nice catch>接得好</ruby>`、`<ruby=YoshiHide>良秀</ruby>`）才只留 Y；但讀音本身就是台詞內容時（例如角色糾正名字的唸法：良(Ryō)……秀(shū)／良秀(Yoshihide)），保留「Y(X)」
  - 口齒不清或扭曲的台詞，草稿用 ruby 標出原意時，寫成「Y(X)」（例如「你唔可仍(你不可能)」）
  - X 只是解釋 Y 的字義、沒有雙關時（例如 `<ruby=明亮>玲瓏</ruby>`），把意思融入句子，不加括號
  - 幼兒口齒不清（愚人節幼稚園劇情等）：只在 KR 本身口齒不清的地方，用臺灣的「臭奶呆」諧音字表現（素＝是、偶＝我、園長大銀＝園長大人），其餘照常翻譯
- **句末標點跟 KR**：疑問語尾但 KR 用句號時（例如 `…건가.`），譯文保留 `。`

## 第二人稱：您／你

- 角色檔（`characters/*.md`）與本節衝突時，以角色檔為準（例如辛克萊對所有人用「您」）

依 KR 原文決定（已決定）。KR 的語體能分辨「你」，但「您」還要看對象：

| KR | 譯法 | 既有繁中的對應 |
|---|---|---|
| 반말（常體） | **你** | 你 2,061 行／您 51 行（98% 你） |
| 하오체（~오、~소，古風的平輩語體，如李箱） | **你** | 你 156／您 38 |
| 존댓말（합쇼체 ~니다、해요체 ~요），且對聽者有敬語標記：`-님`、聽者動作上的 `-시-`（`하세요`、`하셨`、`계시`）、`드리다`、`께서` | **您** | 有標記時 61% 用您 |
| 존댓말，但對象是敵人、對手或陌生人，或只是客套而無敬語標記（E.G.O 戰鬥語音常見，如 `당신을… 청소하라고`） | **你** | 無標記時 28% 用您 |

- 極古風的語尾（`~노라`、`~리라`、`~느니라`），例如節制公貝特朗，可用「吾」「汝」，以同檔既有譯文為準
- KR 的「당신」本身不帶敬意（常用於爭執、對敵、詩化語氣），不能單憑「당신」譯「您」
- 角色例外寫在各角色檔：唐吉訶德用「汝」；鴻璐稱但丁「但丁閣下」時配「您」
- 同一角色的不同人格可能不同：血鬼唐吉訶德（`Voice_DonQuixote_Bloodfiend_10310`）用합쇼체對家主說話，譯為「我」「您」

## 性別：你／妳、他／她

依對象性別區分（已決定）。

- 對女性用「妳」「她」，對男性用「你」「他」
- **但丁性別不明**：一律用「你」「他」（見浮士德原指引：「對但丁在一般情況下使用兩性通用的『他』」）
- 對象性別不明或是群體時，用「你」「你們」「他們」
- 對單一女性說「你家」時寫「妳家」；「你們／妳們」只用於多人
- 各角色性別寫在 `characters/*.md` 的 `gender` 欄位
