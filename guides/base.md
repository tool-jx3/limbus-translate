# 共通翻譯原則

## 原則

- **來源語言**：以 KR 韓文為主，JP 日文與 EN 英文作為輔助。KR 與 EN 意思不同時，依 KR
- **指引沒寫到的情況**：包括格式問題，依 KR 判斷，並在 `note` 說明
- **指引的優先順序**：角色指引優先於族群指引，族群指引優先於本檔；但本檔的格式規則與詞彙表不能被角色風格推翻
- **詞彙表**
  - **一般用語**：`check: off` 的條目（例如 소모、부위、대상）的 `zh` 只是預設譯法，可依中文語法合併、省略或換成自然的同義詞，不必寫 `note`；但 `forbidden` 照樣不可用（例如 계획 不寫「計劃」）：`머리 부위` → 頭部、`버스에서 내리라고` → 讓你們下車、`비용 소모 없음` → 免費
  - **JP、EN 都省略的詞**：KR 有詞彙表的詞，而 JP 與 EN 都沒有寫出時，中文也可以省略，`note` 寫出省略的 KR 原詞（例：「제6회 발푸르기스의 밤 특정 추출」，JP、EN 只寫「第6回ヴァルプルギスの夜」「The 6th Walpurgis Night」）

## 代碼與標籤

### `[ID]`

- **`[ID]` 一律保留**：`[]` 裡放的是效果的英文 ID，遊戲會顯示成效果名稱（`[Laceration]` 顯示為「流血」）。KR 寫 `[ID]` 的地方，譯文也必須寫同一個 `[ID]`，不翻譯、不改動，也不用中文＋空格替代。`<>` 裡的英文同樣不翻譯、不改動
- **`[ID]` 的空格**：`[]` 前後須各空一格半形（`[]` 位於開頭則前方不需空格，遇到全形符號不需空格）；`[]` 與 `[]` 相鄰時，彼此之間空一格半形；`[ID]` 後面緊接 `<style>` 時不空格。名稱裡緊接的 `[英文]` 也是 `[ID]`，前面照樣空格：`못[Console]` → 釘 [Console]。`<>` 前後則無須空格
- **`[TabExplain]`**：用來阻擋關鍵字觸發，沒有任何效果。`[` 前不可以空格，`]` 後若需要空格可以空格

### 佔位符與替換變數

- **`[{n}]` 佔位符**：方括號緊貼，前後不加空格（「罪人[{0}]」「[{0}]獲得了」）；這和 `[ID]` 的空格規則不同
- **全大寫的替換變數**（如 `[ATTRIBUTES]`）是程式在執行時代入的值，前後**不加空格**：`擁有[ATTRIBUTES]屬性攻擊技能的`
- **字面的 `\n`**：KR 文字中出現反斜線加 n（`\n` 兩個字元，不是真正的換行）時，譯文在對應位置照樣保留

### 標籤

- **開始與結束**：在格式 `<XXX="這是">文字內容</XXX>` 中，`<XXX>` 是開始，`</XXX>` 是結束，不可以讓它變成 `</XXX>文字內容<XXX="這是">`
- **種類與數量同 KR**：KR 帶的標籤（如 `<style>`），譯文要有同樣的種類與數量，不可漏掉
- **多出的結束標籤**：KR 開了沒關的標籤（例如歌詞的 `<style="dkr">`），譯文可以在句尾補上對應的結束標籤，官方 EN 版也這樣寫；其他標籤數量仍須與 KR 相同。補上的結束標籤一律放在整段譯文的最後、句末標點之後（`……活動！</color>`），不可放在句子中間
- **少了的開頭標籤**：KR 關了沒開的標籤（例如歌詞 `<style="dkr">몸을 둥글게</size> 말고` 只有 `</size>`）時，譯文可以照 JP 或 EN 補上開頭標籤，屬性也照 JP／EN（`團成一個<size=20>小球</size>`）；補的數量不可多於 KR 少的數量，而且必須在對應的結束標籤之前
- **強調標籤只包 KR 包住的部分**：`<style="highlight">2</style> 부여` → 使目標增加<style="highlight">2</style>級……（「級」在標籤外）
- **只標一個音節的標籤**：KR 用標籤標出雙關的一個音節時（例如 `크<size=110%>랲</size>게`），譯文包住承載雙關的整個中文詞（`<size=110%>廢料蟹</size>`），同系列檔案寫法一致

### ruby

- **ruby 注音**：KR 的 `<ruby=注音>本文</ruby>` 中，注音是顯示在本文上方的文字，要和本文一起翻譯（例如 `<ruby=천퇴성>삽시호</ruby>` → `<ruby=天退星>插翅虎</ruby>`）；標籤本身保留；KR 沒有的 ruby 只在劇情台詞加，`<rubycustomize>` 只在白名單位置加，見「ruby 的位置」
- **ruby 的位置**：遊戲只在劇情台詞（`StoryData/` 的 `content`）處理 `<ruby>`；白名單位置（劇情的說話者名稱、人格語音、播報員、戰鬥氣泡）用 `<rubycustomize>`。有這些位置的檔，批次附有 `guides/shared/ruby.md`，照它寫
  - **其他位置**（不是劇情台詞，也不是帶 `ruby_customize` 的單位）：`<ruby>` 照原樣顯示。KR 沒有 `<ruby>` 時譯文也不加；參考譯文的 `<ruby=X>Y</ruby>` 改寫成「Y(X)」（半形，例如「沒有異常(李箱)」；口齒不清或扭曲的台詞標出的原意也這樣寫），不可直接刪掉。X 只是外語原文或讀音、沒有雙關時只留 Y（`<ruby=YoshiHide>良秀</ruby>`）；只解釋字義、沒有雙關時把意思融入句子，不加括號（`<ruby=明亮>玲瓏</ruby>`）；只是著重點時只留本文（`<ruby=．>歌</ruby>`）；X 是 Y 的原文名稱、而且依規定寫原文時寫 X（源質之樹 `<ruby=Sephirot>生命之樹</ruby>` → Sephirot）

## 標點與書寫

| 項目 | 寫法 |
|---|---|
| 逗號、句號、冒號 | 全形 `，`、`。`、`：` |
| 刪節號 | `……` |
| 引號 | `「」`、`『』` |
| 波浪號 | `～`（全形） |
| 破折號 | `——` |
| 驚嘆號、問號 | 全形 `！`、`？` |

- **括號依文本類型**：
  - 說明戰鬥效果的文字用半形「()」：技能、被動、狀態、E.G.O 飾品、敵人的名稱與說明，鏡牢的起始增益與事件選項的效果（`messageDesc`），異想體事件的結果紀錄（`AbEventsResultLog`）、選擇事件的效果（`ChoiceEventEffect`）、戰鬥提示（`BattleResultHint*`、`BattleHint*`）、活動任務的戰鬥條件；KR 在韓文音譯後的括號附原文時例外，寫「中文意思（原文）」、用全形（見「KR 已在括號附上原文」）；這條對所有族群都適用，戰鬥說明族群（敵人、盟友、關鍵字、鏡牢）的細則見 `guides/shared/battle-text.md`
  - 其他文字用全形「（）」：劇情、台詞、介面、教學、目錄、事件敘述與 RPG（含道具說明，見 `families/rpg.md`），戰鬥族群檔案裡的這類文字也是（`MirrorDungeonUI*`、`TutorialMirrorDungeon`、`StoryTheaterMirrorWorld`、事件的 `desc`／`message`／`result`／`name`）；括號內只有時區、佔位符、英文或編號時也用全形（「（GMT+8）」「（{0}）」）；全形「（」前不加半形空格
  - 例外：其他位置把 ruby 改寫成的「Y(X)」用半形（見「ruby 的位置」）；亂碼與遮蔽字串的符號照原樣（見「亂碼與遮蔽字串」）
- **E.G.O**：`E.G.O` 一律寫成「E.G.O」，結尾不加「.」。KR 句末寫 `E.G.O.` 時，最後一點是句號，寫「。」（「阿賴耶的E.G.O。」）；句中直接接後面的字（「E.G.O的感應度」）
- **只有數字或符號的 KR**：照抄，只把標點換成上表的寫法（例如 `...` → `……`、`?!` → `？！`）
- **只有刪節號的行**：KR 只有 `…`、`……` 或 `…….` 時一律寫 `……`；刪節號後面不加 `。`（JP 的 `……。` 是日文習慣）
- **換行**：KR 有換行時，譯文在對應的位置換行
- **清單符號**：KR 的 `·` 寫成 `．`
- **句中的 `·`**：並列詞語（`지·용·인`、`살·피·뼈`）寫「、」（例：智、勇、仁）；已有譯名的專有名詞照譯名（`산나비·죽은나비` → 生蝶．亡蝶）
- **亂碼與遮蔽字串**：KR 以符號表示的亂碼或遮蔽字（例如 `#&*()!#%의 #*%`）符號照原樣保留、不轉成全形，只翻譯其中的韓文（`의` → `的`）
- **句末標點跟 KR**：疑問語尾但 KR 用句號時（例如 `…건가.`），譯文保留 `。`

## 用語

- **比較用語**：技能、說明、介面文字裡的數值條件都適用：`이상` 不低於、`이하` 不高於、`초과` 高於、`미만` 低於
  - 例如「達到{0}以上」→ 不低於{0}；`체력 50% 미만` → 體力低於50%
  - `N 초과분` 這種「超出的部分」寫「超過N的部分」；否定句 `2 이상 획득 불가` 寫「無法獲得2層或更多」
  - 「差距 N 以上」（`속도가 3 이상 높으면`）寫「高於…至少3點」；「N 이하로 떨어지지 않음」（體力保留 N 點）寫「不會降至N點以下」
  - 台詞裡的慣用語照意思自然地譯，例如 `기대 이하` → 低於預期、`기준치 이하` → 未達標準值
- **樓層**：名稱與介面標籤（說話者名稱、道具名、敵人說明的「4F BOSS」）寫 `3F`、`B2F`（例如「3F 樓層經理」）；**地點欄位**、對話與敘述寫「3樓」「地下2樓」（例如 `심사장 내부 1층` → 會場內部 1樓、`심사장 1층, 죄인의 방` → 會場 1樓，囚犯的房間）
- **用韓文拼寫的外語**：KR 用韓文字母拼寫的外語台詞或感嘆（例如卡利斯托的義大利語 `케 벨로`），寫該外語原文（Che bello），不加括號譯意；劇情台詞與白名單位置改寫中文意思、原文寫在注音，見「ruby 的位置」
- **KR 已在括號附上原文**：KR 已在括號附上原文（`라상블(Rassemble)`、`논(non)`）時，寫「中文意思（原文）」，用全形括號：聚集（Rassemble）、不（non）；劇情台詞與白名單位置（含戰鬥氣泡）改用注音（白名單位置寫 `<rubycustomize>`）、不加括號
- **外語專有名詞**：用韓文拼寫的外語**專有名詞**（船名、地名、組織名）用既有中文譯名，見詞彙表（`리벨리온 드 라스 마사스호` → 大眾的反叛號）；只有台詞、感嘆才寫原文
- **沒有標記的雙關**（KR 沒用 ruby 或標籤，例如 `말`＝話／馬）：能在中文重現就重現（下一句的反應要接得上），重現不了才照字面譯
- **幼兒口齒不清**（愚人節幼稚園劇情等）：只在 KR 本身口齒不清的地方，用臺灣的「臭奶呆」諧音字表現（素＝是、偶＝我、園長大銀＝園長大人），其餘照常翻譯

## 人稱與稱呼

### 第二人稱：您／你

依 KR 原文決定。KR 的語體能分辨「你」，但「您」還要看對象：

| KR | 譯法 |
|---|---|
| 반말（常體） | **你** |
| 하오체（~오、~소，古風的平輩語體，如李箱） | **你** |
| 존댓말（합쇼체 ~니다、해요체 ~요），且對聽者有敬語標記：`-님`、聽者動作上的 `-시-`（`하세요`、`하셨`、`계시`）、`드리다`、`께서` | **您** |
| 존댓말，但對象是敵人、對手或陌生人，或只是客套而無敬語標記（E.G.O 戰鬥語音常見，如 `당신을… 청소하라고`） | **你** |

- 有禮貌的複數稱呼寫「各位」，**不寫「您們」**；同一個說話者在同一個檔案裡對同一群人要用同一種稱呼
- 極古風的語尾（`~노라`、`~리라`、`~느니라`），例如節制公貝特朗，可用「吾」「汝」，以同檔既有譯文為準
- 長輩或師長（父母、師父）對晚輩、孩子說話時，若존댓말只是說話習慣（例如約指父 약지아비 對弟子用 그대＋-시-），用「你／妳」，與既有譯文一致
- KR 的「당신」本身不帶敬意（常用於爭執、對敵、詩化語氣），不能單憑「당신」譯「您」
- 角色例外寫在各角色檔（`characters/*.md`），與本節衝突時以角色檔為準：辛克萊對所有人用「您」；唐吉訶德用「汝」；鴻璐稱但丁「但丁閣下」時配「您」
- 同一角色的不同人格可能不同：血魔唐吉訶德（`Voice_DonQuixote_Bloodfiend_10310`）用합쇼체對家主說話，譯為「我」「您」
- 對俘虜、敵人刻意客氣（帶 `-시-` 的反諷、嘲弄式敬語，例如推奴手鴻璐對抓到的逃奴說 `도망치시려는`）用「您」，保留反諷語氣；沒有 `-시-` 的客套仍用「你」

### 稱呼：~씨、~군、~양

角色檔另有規定時以角色檔為準。

| KR | 譯法 | 例 |
|---|---|---|
| `~씨` | 先生／小姐（依性別） | `유리씨` → 尤莉小姐 |
| `~군`（對男性） | 先生；**辛克萊只寫名字** | `홍루 군` → 鴻璐先生、`히스클리프 군` → 希斯克利夫先生、`싱클레어 군` → 辛克萊 |
| `~양`（對女性） | 女士 | `파우스트 양` → 浮士德女士、`오티스 양` → 奧提斯女士 |

- 格里高爾用「小姐」（`파우스트 양` → 浮士德小姐，見 `characters/gregor.md`）
- 職稱或稱呼加 ~군（`조수 군`）只寫職稱：助手
- 唐吉訶德對所有人都用「~군」，女性也一樣：見 `characters/donquixote.md`（浮士德小姐；良秀、以實瑪利、奧提斯、羅佳直呼名字）

### 性別：你／妳、他／她

依對象性別區分。

- 對女性用「妳」「她」，對男性用「你」「他」
- **但丁性別不明**：一律用「你」「他」
- 對象性別不明或是群體時，用「你」「你們」「他們」
- 性別不明的單一對象（例如普依）不用「他」「她」，改寫成名字或省略；KR 用「그것」稱呼時用「它」
- 對單一女性說「你家」時寫「妳家」；「你們／妳們」只用於多人
- 各角色性別寫在 `characters/*.md` 的 `gender` 欄位。**女性罪人**：浮士德、唐吉訶德、良秀、以實瑪利、羅佳、奧提斯（還有卡戎）；常見女性 NPC：綺羅、櫻桃、以斯拉、林慶業、摩西、瓦倫奇娜、簡。對她們說話時，加了第二人稱就用「妳」
