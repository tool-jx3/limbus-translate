# 劇情標籤欄位（共用指引）

劇情畫面上不是句子、而是短標籤的欄位：說話者名稱（`teller`、`ScenarioModelCodes` 的 `name`、RPG 對話的 `speaker`、異想體對話 `AbDlg` 的 `teller`）、RPG 的 NPC 與道具名稱（`displayName`）、稱號（`StoryData` 的 `title`、`ScenarioModelCodes` 的 `nickName`）、地點（`place`）。

## 格式慣例

- **地點欄位**：`place` 的各層地點之間用半形空格隔開，例如組織或區域與其中的地點、地點與「內部」「外部」「甲板」等下層位置（「梅菲斯托費勒斯 內部」「N公司 薛西弗斯塔 外部」「N公司 某處」）；KR 用逗號分隔時寫全形「，」、不另加空格（「14區，放映室」）；兩者並存時都照做（`마사스호, 선교 내부` → 「大眾號，艦橋 內部」、`과거, 메피스토펠레스 내부` → 「過去，梅菲斯托費勒斯 內部」）；一個名稱本身不加空格（「小指的長廊」「環指父輩的長廊」）。KR 地點本來就寫 `7F` 時照寫「7F」。說話者名稱（teller、ScenarioModelCodes）照既有寫法（例如「中指 父輩」），但詞彙表的譯名優先（`르루주` 寫「丹紅派」，不寫「丹紅」）
- **稱號與說話者名稱的空格**：劇情的稱號（`title`）與說話者名稱裡，組織與職稱、地點之間空一格：「食指 父輩」「中指 幼弟」「J公司 賭場」「Cinq協會 4科」「鐵工會 老大」
- **不留結尾空格**：說話者名稱、稱號、地點不是技能、效果名稱那種「名稱＋空格」的格式，不留結尾空格
