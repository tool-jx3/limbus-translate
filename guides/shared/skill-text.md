# 技能文字（共用指引）

技能、被動、狀態、E.G.O 飾品等說明文字裡，狀態、數值與關鍵字名稱的寫法。

## 格式慣例

- **遊戲會處理關鍵字的欄位**：遊戲只在下列欄位把狀態名稱變成圖示與連結。下面「名稱後加空格」「`<noparse>`」的規則只用在這些欄位；其他欄位（`Bufs*`、`BattleKeywords*` 的 `desc`／`summary`，各種 `name`、`flavor`，劇情與介面）遊戲照字面顯示，名稱後不加空格、不新增 `<noparse>`，其餘寫法照舊
  - `Skills*`：`desc`、硬幣的 `desc` 與 `summary`
  - `Passive*`、`Passives*`：`desc`、`summary`
  - `EGOgift*`：`desc`、`simpleDesc`
  - `PanicInfo*`：`lowMoraleDescription`、`panicDescription`
- **強度、回數、層數**：有強度與層數的狀態照這個格式寫：`1級 [Laceration] 強度`、`1回 [Laceration]`、`1層 [Vulnerable]`；不寫成「1級 [Laceration] 」（少了「強度」）、「1回 [Laceration] 回數」、「1層 [Vulnerable] 層數」。「強度與回數之和」這類把「強度」「回數」「層數」當名詞用的句子不在此限
- **KR 寫韓文狀態名、沒有 `[ID]` 時**：寫官方中文名，名稱後加一個半形空格（「1級燒傷 強度」「2層守護 」「2層強壯 ，」）；遊戲在名稱後面是空格時把它連成關鍵字，後面是中文字或全形標點時不會。限上面列的欄位。官方中文名以語言包的 `Bufs*`／`BattleKeywords*` 為準。**既有譯文不必為了這個空格改**
- **「名稱＋空格」的空格是格式的一部分**：上面列的欄位裡，技能、效果等的中文名稱後面接空格（例如「使目標震顫引爆 」，KR `진동 폭발`）時，這個空格在句尾也保留，不因 KR 沒有而刪掉；同一句的寫法照既有多數。分類標籤不是這種格式，不留結尾空格
- **戰鬥的開始**：`~상태로 전투 시작`（遭遇開始時的初始狀態）寫「關卡開始時，…」或「以…狀態進入戰鬥」；只有每回合的 `전투 시작 시`（[StartBattle]）才寫「戰鬥開始時」
- **技能文字的動詞**：`[X] N 얻음` 寫「使自身獲得N級 [X] 強度」；`[X] 횟수 N 증가` 寫「使目標增加N回 [X]」，不寫「對目標施加」；`[X] N 소모` 寫「消耗N… [X]」，不加「使自身」；硬幣效果的 `크리티컬 피해량 +N%` 寫「使本硬幣暴擊時造成的傷害+N%」
- **消耗數值的代稱**：`(소모한 수치)`、`(소모값)` 依消耗的東西寫「消耗的層數」「消耗的回數」「消耗的強度」，不寫「消耗值」「消耗數值」「消耗量」
- **並列數值的單位**：單位只在最後寫一次：`3/5 이상` → 不低於3/5級，不寫「3級/5級」
- **數值之間的斜線**：技能、被動等說明裡並列的數值或狀態（`3/6/9층`、`66%/33%`）照 KR 寫半形 `/`，前後空格也照 KR；兩個 `[ID]` 之間的斜線前後各空一格（`[UnlockBuff_2] / [UnlockBuff_3]`）
- **除法**：照 KR 寫半形 `/`（`(소모한 수치 / 10)` → (消耗的層數/10)）；既有的「÷」不必改
- **`<noparse>`**：遊戲會把說明文字裡的關鍵字名稱讀成那個關鍵字，`<noparse>…</noparse>` 包住的文字不會（例如 `攻擊等級+` 是 `[AttackLevelAdder]` 的名稱，「攻擊等級+1」會被讀成它，要寫「<noparse>攻擊等級+</noparse>1」）。KR 與中文的關鍵字名稱不同，所以譯文的 `<noparse>` 位置與數量可以和 KR 不同：KR 包住的詞，中文也是關鍵字名稱時照樣包；draft、既有譯文與人工調整已有的 `<noparse>` 不要刪掉；新增只限已在遊戲中確認會被讀成關鍵字的地方。`<noparse>` 要成對、不可巢狀，裡面只放文字，不放標籤與 `[ID]`（遊戲會照字面顯示）
